# churn-intercon
**Problema de Negócio:** Identificar clientes com elevado risco de cancelar serviços de telecomunicações para apoiar campanhas preventivas de retenção. 
**Solução:** Unificação de múltiplas bases de dados, engenharia de atributos (*tenure*, faturação) e comparação entre Regressão Logística, Random Forest e Gradient Boosting.
